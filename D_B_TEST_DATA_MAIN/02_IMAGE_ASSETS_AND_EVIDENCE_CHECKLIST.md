| 5 | `s00001-blurred-pump.jpg` | 图片模糊人工复核 | `TEAM_SYNTHETIC_AUGMENTATION` | | ☐ 未交付 | |

### 交付前必须逐张确认

- ☐ 文件真实存在，模型能读取（不是只有文件名）
- ☐ 图片里没有真实消费者身份信息（人脸、姓名、地址、手机号、订单号截屏）
- ☐ 每张图都有明确来源标记
- ☐ 图片内容与用途对得上：1–3 用于主拦截；4 用于范围变化；5 用于人工复核
- ☐ 清晰图与模糊图除清晰度外，商品与角度尽量一致（否则 A26 的对照不成立）

### 为什么这是最高优先级

`docs/07` 门 2 要求「至少一个案例从原始聊天和实际图片文件生成 `ExtractedJourney`」。没有图片文件，门 2 直接失败，主 Demo 的 1:00–1:40 段也演示不了。见 `A_验收清单/09_阻塞与待确认清单.md` T-01。
