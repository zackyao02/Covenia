# 10｜情绪判断依据、推断标识与行动边界

## 1. 目的

情绪字段用于帮助客服理解消费者当前表达方式、选择更合适的沟通语气，并定位需要被确认的服务经历。它不是消费者人格标签，不是质量责任结论，不直接改变体验防线规则，也不构成经过验证的投诉或舆情预测。

本规范要求每个情绪结论同时回答三个问题：

1. 判断依据来自哪段对话或哪个事件？
2. 哪些内容是原始事实，哪些内容是系统推断？
3. 该推断怎样辅助客服行动，但不替代事实、权限和规则？

## 2. 输出结构

`CustomerState.emotion` 分为四层：

| 层级 | 字段 | 含义 |
|:---|:---|:---|
| 原始依据 | `events[].source_id / quote / at / observed_cues` | 可回到原始消费者消息的引用、时间和显式词语 |
| 单条推断 | `events[].inference` | 对该消息的情绪标签、强度、置信度和方法，固定标记 `is_inference: true` |
| 跨事件推断 | `inferences[]` | 当前情绪、趋势和可能原因，包含 `derived_from` 来源 ID |
| 行动辅助 | `action_support[]` | 给客服的表达和确认建议，包含所依据的来源 ID |

所有推断必须带来源，不允许只返回 `emotion: ANGRY` 而无法解释依据。

## 3. 事实与推断的界线

以下属于可核验事实：

- 消费者消息原文、消息 ID 和发送时间。
- “投诉”“已经发过”“怎么还要”等原文中实际出现的词语。
- 联系次数、等待时长、重复索证事件和承诺是否超时。

以下属于推断：

- `CONCERNED / FRUSTRATED / ANGRY` 等情绪标签。
- 情绪是否呈 `ESCALATING` 趋势。
- 情绪可能由重复请求或等待无更新引起。

推断必须显示置信度和方法。当前比赛实现使用 `LEXICAL_CUE_DEMO_RULE`，仅用于演示，不声称具备跨行业、方言、反讽或文化差异下的稳定准确率。

## 4. 如何辅助客服行动

情绪信息仅支持以下低风险辅助：

- 提醒客服先确认消费者已经做过的事情。
- 建议采用简短、直接、承担责任的表达。
- 建议说明明确的当前进度、责任方和下一更新时间。
- 提醒客服人工查看原文，避免只依赖摘要或标签。

情绪信息不得单独触发：

- 拦截或放行客服动作。
- 自动升级主管、转人工或关闭案件。
- 退款、赔偿、补发、责任认定或承诺生效。
- 对投诉、流失、曝光或舆情结果作预测。

Next Best Action 仍由证据状态、消费者意图、已尝试动作、承诺状态、权限和确定性服务事件共同决定。

## 5. 与现有规则和 Risk Score 的关系

`emotion.governance` 固定声明：

```json
{
  "advisory_only": true,
  "overrides_existing_rules": false,
  "included_in_risk_score": false,
  "prediction": false
}
```

体验防线继续只依据服务端恢复的证据、范围、禁止动作、高风险业务类型和案件完成条件运行。情绪标签不参与 `P0_PROHIBITED_ACTION / E1 / E2 / H1` 的求值。

Risk Score 被定义为 **Operational Triage Score**，只汇总已经发生的可验证服务事件，例如重复联系、重复索证、未解决工单、承诺临期或超时，以及消费者明确说出的投诉升级关键词。情绪作为 `context_signals` 返回，固定 `weight: 0`、`used_for_score: false`。

这一区分意味着：即使同一段事实被推断为不同情绪，体验防线决策和 Operational Triage Score 也必须保持不变。

## 6. 界面要求

客服侧必须同时展示：

- 原文引用。
- 消息 ID 与时间。
- 匹配到的显式线索。
- “推断”标签与置信度。
- 可执行的沟通辅助建议。
- “不参与 Risk Score、不覆盖现有规则”的固定说明。

Risk Radar 可以展示情绪作为上下文列，但 Why 区域的计分项只能来自实际参与评分的服务事件。情绪不得伪装成带权重的风险原因。

## 7. 验收标准

| ID | Given | When | Then |
|:--:|:---|:---|:---|
| EM1 | 任一情绪事件 | 查看 API 和界面 | 可定位到 `source_id`、原文和时间 |
| EM2 | 任一情绪字段 | 查看结构 | 明确标记为推断并带置信度与方法 |
| EM3 | 仅修改情绪措辞，不改变服务事件 | 重算 Risk Score | 分数保持不变 |
| EM4 | 情绪标签变化 | 评估同一 PreparedAction | 体验防线规则与决策保持不变 |
| EM5 | Risk Radar 展示 Why | 查看评分因素 | 不出现带权重的情绪因素 |
| EM6 | Copilot 展示情绪 | 查看行动建议 | 仅提供表达、确认和阅读原文建议 |
