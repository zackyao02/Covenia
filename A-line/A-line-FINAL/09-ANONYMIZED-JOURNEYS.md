| 品类 | 外卖（非美妆） |
| 时间线 | 下单后约 30 分钟被取消/送错 → 客服要求提交订单列表、截屏与实物照片 → **反复核对约 10 分钟** → 承诺补偿券 → 约 5 小时后仍未到账 → 消费者主动追问 → 被告知「申诉已结束」，只能转门店 → 无下文 |
| 消费者提交材料次数 | 首次 1 轮（截屏 + 实物照片）；重复多轮核对 |
| 商家承诺原文 | 「稍后会补给你（补偿券）」（无具体时间） |
| 承诺是否按时兑现 | 否 |
| 中断点 | 承诺超时 + 假性结案；消费者已经提交过的信息被反复索取，责任被推回给消费者 |
| 可引用结论 | ① 同一案例可同时出现重复举证、承诺超时与假性结案；② 承诺作出后，追踪责任应留在品牌侧；③ 主动提前说明能显著降低情绪恶化 |
