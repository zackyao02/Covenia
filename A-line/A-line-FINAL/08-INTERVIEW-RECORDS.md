## 2. 逐份记录

### C-01｜唇釉疑似真伪：消费者主动放弃交涉

| 字段 | 内容 |
|---|---|
| 品类/场景 | 唇釉（美妆）；在美妆集合店低价购入，与官方旗舰店对比后怀疑真伪 |
| 经历摘要 | 消费者发现包装字体略歪、印刷颜色与保质期旁编号格式不同，但无法据此判定为假；出于「唇釉会进嘴」的安全考虑，直接以七天无理由退货结束，**没有与客服理论，也没有在评论区指控** |
| 提交材料次数 | 0 次（未进入客服举证环节） |
| 与假设的关系 | **一致 + 反例**：支持「重复举证会让人恼火」，同时补充「维权成本高时消费者会直接放弃交涉」这一沉默成本 |

关键原话（≤3 条）

1. 「因为我觉得在这种情况下跟他们 argue，是成功率不高的一件事情。」
2. 「你说的那个提供，不是发过一遍了吗？他为什么要发第二遍？」
3. 「如果他会提前跟你说『亲，我可能看不到你们之前的聊天记录』……那当然心里会好一点。」

产品含义：证据恢复不只是「少要一次照片」，还包括对「为什么上一环节看不到记录」给出可解释的说明；跨客服信息断点是可被消费者直接感知的。

### C-02｜运动鞋维修：未经同意更换材料、说明不透明

| 字段 | 内容 |
|---|---|
| 品类/场景 | 运动鞋维修（非美妆） |
| 经历摘要 | 商家在未征得同意的情况下用另一种材料维修鞋子，消费者反复询问未得到清晰说明；商家还发来「照片上看差不多」的回复，未说明材料已更换 |
| 提交材料次数 | 商家侧拍照为主；消费者反复沟通 |
| 与假设的关系 | 一致：支持「承诺与说明必须具体、可追踪」；信息不透明直接造成困扰 |

关键原话（≤3 条）

1. 「我觉得确实是你们服务没有做到位。」
2. 「我认为你的价格应该是包含了你的这个保护壳和钢化膜，所以让我挺难受的。」

转述（非原话，已标注）：受访者对客服的机械性敷衍回复不满，更在意「到底几天能到」这类确切时间。

> 记录完整性：本份转写稿部分段落不完整、语义中断，本文件仅采用可确认内容；未采用无法还原的片段。

### C-03｜外卖送错：重复举证 → 承诺超时 → 假性结案（最强案例）

| 字段 | 内容 |
|---|---|
| 品类/场景 | 外卖（非美妆） |
| 经历摘要 | 下单后被取消/送错；客服要求提供订单列表、截屏与实际收到的货物照片，**反复核对约 10 分钟**；随后承诺给补偿券，约 5 小时后仍未到账；再次询问时被告知「申诉已结束」，只能转交门店，此后没有下文 |
| 提交材料次数 | 首次提交 1 轮（截屏 + 实物照片），此后被反复要求核对多遍 |
| 承诺原文（脱敏） | 「稍后会补给你（补偿券）」——无具体时间 |
| 是否按时兑现 | 否 |
| 与假设的关系 | **强烈一致**：同一案例同时命中重复举证、承诺超时、假性结案，可直接支撑 Covenia 主链叙事 |

关键原话（≤3 条）

1. 「他让我提供了一些很多没必要的信息。」
2. 「从他承诺说他要给我补发开始，就应该是由他来负责……这本身就是他职责范围内的事情，应该他来兑现。」
3. 「（如果他提前跟我说）我可能就没有那么多顾虑，然后就不会那么的烦躁。」

产品含义：证据范围要「最小必要」；承诺一旦作出，追踪责任应在品牌侧，而不是回到消费者；主动同步能显著降低情绪恶化。

### C-04｜平台升级退款：反例与升级路径价值

| 字段 | 内容 |
|---|---|
| 品类/场景 | 淘宝衣服质量问题退货（非美妆） |
| 经历摘要 | 卖家不同意退货，消费者转而找平台售后介入，最终退款成功；消费者本人对重复提交材料持「无所谓」态度 |
| 提交材料次数 | 仅 1 次 |
| 与假设的关系 | **反例（必须保留）**：并非所有消费者都反感重复提交；同时支持「找不到客服 / 需要升级到平台」才是核心痛点 |

关键原话（≤3 条）

1. 「无所谓啊，我觉得你有需求找人家，人家提供一下也正常嘛。」
2. 「生气的就是找不到客服。」
3. 「有时候那个固定的那个客服没啥用，感觉就是那种机械式回答的客服，解决不了根本问题。」

产品含义：「重复举证」不是对每个人都同等严重，产品价值主张应聚焦「已有的证据不该再要一遍」这一客观规则，而不是替消费者做情绪判断；同时证明「升级路径要清晰」。

### C-05｜限量圣诞日历：承诺超时 + 换客服重复举证（美妆品类）

| 字段 | 内容 |
|---|---|
| 品类/场景 | 限量圣诞日历（美妆/礼品，连卡佛渠道） |
| 经历摘要 | 预定价 4000+，后涨到 7000+；卖家称「货被海关扣了」迟迟不发货，但店铺仍在加价售卖并有新评价；消费者截图举证（店铺仍在售 + 评价），并咨询律师与查案例后维权成功，最终发货 |
| 提交材料次数 | 截图举证；因更换客服而需要重复提交 |
| 承诺原文（脱敏） | 承诺发货（未按时兑现，以「海关扣货」为由） |
| 是否按时兑现 | 否 |
| 与假设的关系 | 一致：支持「换客服导致重复举证」与「承诺未到期就应主动预警」 |

关键原话（≤3 条）

1. 「（重复提交材料的原因为）就换一个客服吧，比如说。」
2. 「如果你做不到，你可以把时间延长一些；或者你在开始就说是……因为一些意外导致没有办法按时发货。」
3. 「那总不能等到到点了再去问他，我觉得那会儿客户肯定会生气的。」

产品含义：承诺未到期就应预警与主动更新；跨客服的证据恢复是刚需，不是锦上添花。
